# جیمیل‌بین (MailBin)

اکستنشن کروم برای دیدن ایمیل‌های خوانده‌نشده جیمیل بدون باز کردن جیمیل، شبیه Checker Plus for Gmail.

اکستنشن با همان حساب گوگلی کار می‌کند که در کروم وارد آن شده‌اید. رمز عبور، API Key یا Google Cloud لازم ندارد.

## امکانات

- **شمارنده روی آیکون:** تعداد ایمیل‌های خوانده‌نشده را نشان می‌دهد. اگر وارد جیمیل نشده باشید `?` و اگر اتصال قطع باشد `!` نمایش داده می‌شود.
- **لیست ایمیل‌ها در پاپ‌آپ:** فرستنده، موضوع، چند خط اول متن و زمان (مثلاً «۵ دقیقه پیش»).
- **چند حساب:** همه حساب‌های گوگلی که در کروم وارد شده‌اند را خودش پیدا می‌کند.
- **خواندن ایمیل داخل پاپ‌آپ:** متن کامل ایمیل همراه با عکس‌ها و لینک‌ها. اگر ایمیل‌ها جواب هم باشند، همه با هم نمایش داده می‌شوند.
- **پیوست‌ها:** فایل‌های PDF و عکس‌ها داخل پاپ‌آپ یا در یک تب جدید باز می‌شوند. فایل‌های دیگر دانلود می‌شوند.
- **«خوانده‌شده» در خود اکستنشن:** ایمیلی که باز می‌کنید یا تیک می‌زنید از لیست و شمارنده حذف می‌شود. این کار در خود جیمیل تغییری ایجاد نمی‌کند (جزئیات در بخش محدودیت‌ها).
- **اعلان ایمیل جدید:** با کلیک روی اعلان، همان ایمیل باز می‌شود.
- **کد تایید (OTP):**
  - کد ایمیل‌های تایید (فارسی و انگلیسی) پیدا می‌شود و در کلیپ‌بورد کپی می‌شود.
  - اگر در سایتی باشید که کد را خواسته، کد خودکار در فیلد وارد می‌شود. دکمه تایید زده نمی‌شود.
  - وقتی صفحه‌ای فیلد کد تایید دارد، ایمیل‌ها تا ۳ دقیقه هر ۴ ثانیه بررسی می‌شوند.
- **آپدیت از GitHub:** نسخه جدید مستقیم از همین ریپو در پوشه اکستنشن نوشته می‌شود.
- رابط فارسی با تم روشن و تیره خودکار.

## نصب

1. این ریپو را دانلود کنید (Code ← Download ZIP) و از حالت فشرده خارج کنید.
2. در کروم به `chrome://extensions` بروید و **Developer mode** را روشن کنید.
3. روی **Load unpacked** بزنید و پوشه‌ای را انتخاب کنید که فایل `manifest.json` داخل آن است.
4. در همین کروم وارد جیمیل شوید.

## آپدیت

1. در تنظیمات اکستنشن روی **آپدیت از GitHub** بزنید.
2. فقط بار اول: دکمه **انتخاب پوشه** را بزنید، پوشه اکستنشن را انتخاب کنید و اجازه **ویرایش** بدهید.
3. هر وقت نسخه جدید آماده باشد، اعلان می‌آید و پایین پاپ‌آپ نوار «نسخه جدید» نمایش داده می‌شود. روی **آپدیت** بزنید.

اکستنشن هر ۶ ساعت این ریپو را بررسی می‌کند. با آپدیت، فایل‌ها در پوشه نوشته می‌شوند و اکستنشن خودش دوباره بارگذاری می‌شود. همه فایل‌ها اول کامل دانلود می‌شوند و `manifest.json` آخر از همه نوشته می‌شود، پس قطع شدن اینترنت وسط کار آپدیت را نیمه‌کاره نمی‌گذارد.

> ریپو باید **عمومی** بماند؛ در حالت خصوصی آپدیت کار نمی‌کند.

## تنظیمات

| گزینه | توضیح |
|---|---|
| فاصله بررسی | از ۳۰ ثانیه تا ۳۰ دقیقه |
| اعلان ایمیل جدید | روشن / خاموش |
| حداکثر تعداد حساب | تعداد حساب‌هایی که بررسی می‌شوند (۱ تا ۱۰) |
| شمارش ایمیل‌ها | کل صندوق ورودی، یا فقط تب اصلی (Primary) مثل خود جیمیل |
| خوانده‌شده با باز کردن | ایمیل بازشده در پاپ‌آپ از لیست حذف شود |
| جاگذاری خودکار کد تایید | روشن / خاموش |
| کپی کد تایید | روشن / خاموش |
| برچسب (Label) | نمایش یک برچسب خاص به‌جای صندوق ورودی |
| بازگردانی خوانده‌شده‌ها | همه ایمیل‌هایی که در اکستنشن خوانده‌شده کرده‌اید به لیست برمی‌گردند |

## محدودیت‌ها

- **«خوانده‌شده» فقط در اکستنشن ثبت می‌شود.** روش قدیمی که با آن می‌شد بدون API ایمیل را در جیمیل خوانده‌شده کرد دیگر وجود ندارد. برای خوانده‌شده شدن در خود جیمیل، ایمیل را در جیمیل باز کنید. ایمیل‌های خوانده‌شده در اکستنشن بعد از ۶۰ روز از حافظه اکستنشن پاک می‌شوند.
- لیست حداکثر حدود ۲۰ ایمیل خوانده‌نشده آخر هر حساب را نشان می‌دهد. برای بقیه، دکمه «همه خوانده‌نشده‌ها در جیمیل» هست.
- آرشیو، حذف و پاسخ دادن از داخل اکستنشن ممکن نیست.
- متن کامل ایمیل و پیوست‌ها از صفحه‌های داخلی جیمیل خوانده می‌شوند. اگر گوگل این صفحه‌ها را تغییر دهد، ممکن است این بخش‌ها از کار بیفتند. در این صورت متن کوتاه ایمیل و دکمه «باز کردن در جیمیل» نمایش داده می‌شود.

## حریم خصوصی

- اکستنشن فقط با `mail.google.com` (و برای پیوست‌ها `googleusercontent.com`) و برای آپدیت با GitHub ارتباط دارد. هیچ داده‌ای به سرور دیگری فرستاده نمی‌شود.
- برای پیدا کردن فیلد کد تایید، یک اسکریپت کوچک روی همه سایت‌ها اجرا می‌شود. این اسکریپت فقط دنبال فیلد کد تایید می‌گردد و چیزی از صفحه جایی نمی‌فرستد. برای همین کروم دسترسی «خواندن و تغییر داده‌ها در همه سایت‌ها» را نشان می‌دهد.

## ساختار فایل‌ها

| فایل | کار |
|---|---|
| `manifest.json` | تعریف اکستنشن، نسخه و دسترسی‌ها |
| `background.js` | بررسی ایمیل‌ها، شمارنده، اعلان‌ها، خوانده‌شده محلی، کد تایید |
| `popup.html` / `popup.css` / `popup.js` | پاپ‌آپ: لیست، خواندن ایمیل، پیوست‌ها |
| `content.js` | پیدا کردن فیلد کد تایید در سایت‌ها و جاگذاری کد |
| `options.html` / `options.js` | صفحه تنظیمات |
| `update.html` / `update.js` / `update-config.js` | آپدیت از GitHub |
| `viewer.html` / `viewer.js` | نمایش پیوست در تب جدید |
| `offscreen.html` / `offscreen.js` | کپی کد در کلیپ‌بورد |
| `icons/` | آیکون‌ها |

## ساخت نسخه جدید

1. تغییرات را اعمال کنید.
2. عدد `version` را در `manifest.json` بالا ببرید (مثلاً `1.7.0` ← `1.7.1`). بدون این کار آپدیت دیده نمی‌شود.
3. فایل‌ها را در شاخه `main` همین ریپو آپلود کنید.
